Agents can ask you something and wait for the answer. You reply where the message landed: tap a button in Telegram, text back a number, or reply to the email. The agent picks the answer up with `get_replies`.

## Ask a question

Send `notify` with `options` for a multiple choice question, or `expect_reply: true` for a written answer:

```json title="notify input"
{
  "title": "Ship the redesign?",
  "message": "Preview is attached. Staging passed.",
  "priority": "high",
  "options": ["Ship it", "Wait until Monday"],
  "sender_name": "Cat Design Project"
}
```

Then read the answer. `wait_seconds` holds the call open until something arrives, up to 50 seconds. Call again if it comes back empty. For long waits, see [Wait for answers](/docs/agents/waiting).

```json title="get_replies input"
{ "message_id": "msg_123", "wait_seconds": 50 }
```

Each answer has a `kind`:

| Kind | What you did |
| --- | --- |
| `reply` | Sent text, a photo, a voice note, or a file back. |
| `choice` | Tapped a button, or texted the number of an option. `option` has the index and the label. |
| `reaction` | Reacted with an emoji. `text` holds the emoji. |
| `vote` | Answered a poll. |

Beep Me marks answers read when the agent gets them, so each answer reaches the agent once. Pass `include_read: true` to see them again.

## How answers are matched

Each answer from `get_replies` has `from` and `in_reply_to`:

| Field | What it holds |
| --- | --- |
| `from` | `channel_id`, `channel_name`, and `channel_kind` of the channel the answer came from, and `matched_by`. |
| `in_reply_to` | The message it answers: `message_id`, `title`, `topic`, `sent_at`, and `sent_to` (each channel that got the message, including fallback sends). `null` when Beep Me could not tie the answer to a message. |

`matched_by` tells how Beep Me tied the answer to the message:

| Value | How Beep Me matched it |
| --- | --- |
| `reply` | You replied to that exact message, for example a Telegram reply or an email reply in the same thread. |
| `button` | You tapped one of the options. |
| `reaction` | You reacted to that message. |
| `latest` | You wrote in a chat or texted back without a reply. Beep Me picked the newest message on that chat that waited for an answer. This is a guess. |
| `address` | You sent an email to the agent's own address. It is not tied to one message. |
| `dashboard` | You answered in Beep Me, or selected **Got it**. |

A message can go to more than one channel, and a fallback can send it again. An answer on any of those channels attaches to the same message. When `matched_by` is `latest` and the agent has more than one open question, it checks the answer against `in_reply_to.title`.

In Activity, each answer shows the channel name. An answer matched with `latest` also shows "Beep Me matched this to the newest message on that chat that waited for an answer."

## Send files

Add `attachments` to `notify`. Each file is a public `url`, or base64 `data` up to 20 MB with a `filename`. Beep Me keeps uploaded files for 7 days at an unguessable `/media/...` URL so text message providers can fetch them. Channels that cannot show a file get a link to it.

## Sender names

Every message shows the agent that sent it. Set `sender_name` to add a project name, for example "Cat Design Project (Claude Code)". Email uses it as the From name.

## Where you can answer

| Where | How |
| --- | --- |
| Beep Me dashboard | Open the message in [Activity](/) and tap a choice or write an answer. This works for every channel, so Slack, Discord, and Pushover messages link here. Select **Got it** to answer a message that asks nothing. |
| ntfy | Tap a choice button on the notification, for questions with up to 3 options. |
| Telegram | Tap a choice button, reply to the message, or send a plain message, a photo, a file, or a voice note in the chat or topic thread. Emoji reactions count too. The bot reacts 👀 when the agent reads your answer. See [Telegram](/docs/channels/telegram). |
| Text message (Telnyx, Twilio) | Text back. A number or the exact option text picks a choice; anything else is a written answer. Photos come through as files. See [Telnyx SMS](/docs/channels/telnyx) and [Twilio SMS](/docs/channels/twilio). |
| Email (Resend) | Reply to the email. Each agent sends from its own address on your domain, so replies reach the right agent even when they answer no specific message. A one-line number or option text picks a choice, and attachments come through as files. Needs an agent domain and the reply webhook. See [Resend](/docs/channels/resend). |

Each channel page lists what it supports. Open a message in Activity to see its replies, its files, and whether the agent picked them up yet.
