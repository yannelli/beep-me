Deploy Beep Me to your Cloudflare account, get a test message on your phone, and connect Claude Code. The full procedure takes about five minutes.

## Before you start

You need:

- Node.js 24 or later.
- [Bun](https://bun.sh) 1.2 or later.
- A Cloudflare account.
- A Google account. You sign in to Beep Me with it, and you create the sign-in client in Google Cloud.
- Your phone.

## Deploy and connect

<Steps>

### Get the code

Clone the repository and install the packages:

```sh
git clone https://github.com/yannelli/beep-me.git beep-me
cd beep-me
bun install
```

### Run the setup script

```sh
bun run setup
```

The script does these steps:

1. Signs you in to Cloudflare. It opens a browser when you are not signed in.
2. Creates or finds the `beep-me` D1 database and the `beep-me-oauth` KV namespace. It writes their IDs to `wrangler.jsonc`.
3. Asks which Google accounts can sign in. The default is the email in your Git settings.
4. Builds and deploys the Worker with a new random `APP_SECRET`.
5. Shows the Worker URL, for example `https://beep-me.<your-subdomain>.workers.dev`.

If the script cannot read the Worker URL, it asks you to paste it.

### Create the Google sign-in client

The script prints these steps. Do them in a browser:

1. Open `https://console.cloud.google.com/auth/clients/create`.
2. Application type: **Web application**. Name: Beep Me.
3. Authorized redirect URI: your Worker URL with `/auth/google/callback` at the end.
4. Create, then copy the client ID and client secret.

For example, the redirect URI looks like this:

```text
https://your-beep-me.example/auth/google/callback
```

To use the Gmail channel later, also turn on the Gmail API. The script prints this link: `https://console.cloud.google.com/apis/library/gmail.googleapis.com`.

### Paste the client ID and secret

Go back to the terminal. Paste the client ID at the `Client ID` prompt. Paste the client secret at the `Client secret` prompt. The script saves them as Worker secrets.

At the end, the script shows the commands to connect Claude and Claude Code. Keep the terminal open.

### Sign in on your phone

Open the Worker URL on your phone. Select **Continue with Google**. Pick your account.

<Callout type="tip">

Add Beep Me to your Home Screen. On iPhone, tap Share. Then tap Add to Home Screen. On Android, open the menu. Then tap Install app.

</Callout>

### Connect a channel

Open **Activity**. Find the **Get your first message** list. Select **Add channel**. Pick a channel.

ntfy and Telegram take about a minute. ntfy needs no account. See [ntfy](/docs/channels/ntfy) or [Telegram](/docs/channels/telegram).

### Send a test

Open **Activity**. Find **Send a test**. Keep the priority at **Medium**. Select **Send test**.

The message arrives on your phone. Beep Me shows `Test sent to` and the channel name.

### Connect Claude Code

On your computer, run the command that the setup script printed:

```sh
claude mcp add --transport http --scope user beep-me https://your-beep-me.example/mcp
```

Start Claude Code. Run `/mcp`. Select `beep-me`. Start the sign-in. On the approval page, keep the defaults. Select **Allow**.

### Get a message from Claude Code

In Claude Code, send this prompt:

```text
Send me a Beep Me notification that says setup is done.
```

The message arrives on your phone. Open **Activity** in Beep Me to see it with the agent name.

</Steps>

## If something goes wrong

| What you see | What to do |
| --- | --- |
| **Finish setup** | `APP_SECRET` is missing. Run `bun run setup` again. |
| **Set up Google sign-in** | The Google secrets are missing. Run `bun run setup` again. Paste them at the prompts. |
| A redirect URI error from Google | Check that the URI in Google is your Worker URL with `/auth/google/callback` at the end. |
| `is not allowed to sign in to this Beep Me` | Your email is not in `ALLOWED_EMAILS`. See [Configuration](/docs/reference/configuration#allowed_emails). |

For more fixes, see [Troubleshooting](/docs/reference/troubleshooting).
